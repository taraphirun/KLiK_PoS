## Description
Implement global keyboard shortcuts to enhance navigation efficiency for POS operators.

## Estimated Time
45-60 minutes

## Files to Change

## Acceptance Criteria
- `Cmd/Ctrl + F` focuses the search bar.
- `Escape` clears the search bar or deselects search results.
- `ArrowUp / ArrowDown` navigates the search results grid.
- `Shift+Enter` opens the quantity dialog for the highlighted product.

## Risks
- Keybinding conflicts with browser default shortcuts or other existing app shortcuts.
