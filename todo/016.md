# Todo 016: Frontend Global Keyboard Navigation

**Status:** ✅ Done

## Description
Implement global keyboard shortcuts to enhance navigation efficiency for POS operators.

## History
- 2026-07-30: `Cmd/Ctrl+F` focus + scoped `Escape`-to-clear shipped first; grid nav and the
  quantity dialog were split off and deferred (no highlighted-item state or quantity-dialog
  component existed yet, and building both blind without live testing was judged too risky).
- 2026-07-30 (continued): Deferred half completed now that live testing is possible.

## Files Changed
- `klik_spa/src/components/RetailPOSLayout.tsx`: `searchInputRef` + window keydown listener for
  Cmd/Ctrl+F and scoped Escape-clear (desktop only).
- `klik_spa/src/components/SearchBar.tsx`: `forwardRef` for imperative focus; added
  `data-pos-search-input="true"` on the `<input>` so `ProductGrid`'s nav listener can recognize it.
- `klik_spa/src/components/MenuGrid.tsx`: threads `searchInputRef` through to `SearchBar`.
- `klik_spa/src/components/ProductGrid.tsx`: `highlightedIndex` state, `getColumnCount()` (reads
  the grid's live `grid-template-columns` so nav stays correct across responsive breakpoints),
  desktop-only `window` keydown listener for `ArrowUp/Down/Left/Right` + `Shift+Enter`,
  `openQuantityDialogForItem()` (routes variant templates to the existing `VariantPickerModal`,
  concrete items to the new `QuantityDialog`), renders `QuantityDialog`.
- `klik_spa/src/components/ProductCard.tsx`: new `isHighlighted` prop, ring styling.
- `klik_spa/src/components/QuantityDialog.tsx` (new): quantity-entry modal, confirms via
  `addToCartWithQuantity`.

## Acceptance Criteria
- [x] `Cmd/Ctrl + F` focuses the search bar.
- [x] `Escape` clears the search bar (when it has focus).
- [x] `ArrowUp / ArrowDown / ArrowLeft / ArrowRight` navigates the product grid (grid view only).
- [x] `Enter` adds the highlighted product to the cart at quantity 1.
- [x] `Shift+Enter` opens the quantity dialog for the highlighted product.

## Known scope limits
- List view (`ProductLineView`) has no keyboard nav/highlight yet — only grid view. Revisit if the
  user relies on list view as their default (`custom_default_view`).
- Salesperson-PIN gating: if a PIN is required and no salesperson is active, Shift+Enter falls back
  to the existing pending-item + auth-modal flow, which adds at qty 1 after auth rather than
  reopening the quantity dialog. Edge case, not chained further.

## Risks
- Keybinding conflicts with browser defaults or other shortcuts — checked: Cmd/Ctrl+F and Escape
  don't collide with `CustomerSearchSection`/`AutoComplete`'s own Escape handling; arrow keys are
  scoped off whenever any other text input/textarea/contenteditable/modal has focus, and
  ArrowLeft/Right are left alone while the search box itself is focused so text-cursor movement
  still works normally.
