# Todo 015: Verify Existing Customer-Change Dynamic Pricing

**Status:** ✅ Done (verified — no code change needed)

## Description
Originally planned as a new `ProductProvider.tsx` effect listener calling a separate batch-pricing
endpoint on `selectedCustomer` change. That's already unnecessary: `setSelectedCustomer()` in
`productStore.ts` already calls `initializePOS()`, which refetches the full product list
(`fetchProductsFromAPI` → `get_items`) with the newly selected customer's id and price list. The
cache-validity check (`isCacheValid && !effectiveCustomerId && ...`) explicitly skips the cache
whenever a customer is present, so this is never served stale. The returned `items` fully replace
`products` state, so the grid already shows the customer's specific pricing without any additional
listener.
