# Todo 015: Frontend Product Provider Dynamic Pricing

## Description
Implement a state listener that dynamically fetches and updates item prices across the POS whenever a new customer is selected.

## Estimated Time
45-60 minutes

## Files to Change
- `klik_spa/src/providers/ProductProvider.tsx`

## Dependencies
- Todo 014

## Acceptance Criteria
- Effect listener triggers when `selectedCustomer` changes.
- Item price maps are updated using the batch pricing API.
- Product grid prices instantly reflect the customer's specific pricing.

## Risks
- Unnecessary re-renders of the entire product grid if the state updates are not properly memoized.
