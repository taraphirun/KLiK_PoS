# Todo 013: Frontend Payment Dialog Discount Inputs

**Status:** ✅ Done

## Description
Add UI elements for applying additional discounts (percentage or absolute amount) directly within
the Payment Dialog, backed by Todo 012's native-erpnext-fields approach (no client-side discount
math reimplementation). Since the existing `validateCheckoutInvoice` live tax-preview call already
rebuilds the invoice and returns `grand_total`, including the discount fields in that payload is
enough to get real-time recalculation from the backend's authoritative total.

## Estimated Time
45-60 minutes

## Files to Change
- `klik_spa/src/components/dialog/PaymentDialog.tsx`

## Dependencies
- Todo 012

## Acceptance Criteria
- Input fields for Additional Discount (Amount & Percentage) are present.
- `grandTotal` and "change given" recalculate in real-time as discounts are adjusted.

## Risks
- Complex React state updates might lead to inaccurate UI calculations if not synchronized correctly with the backend expectations.
