# Todo 028: Migrate `delivery_driver` Free-Text → `Link(Driver)`

**Status:** ⬜ Not started

## Description
Convert the free-text driver fields introduced in Phase 9 to proper `Link` references now that a
`Driver` master exists (Todo 025), and backfill existing free-text values by matching them to
driver records.

## Estimated Time
1-2 hours

## Files to Change
- `klik_pos/klik_pos/doctype/delivery_report/delivery_report.json` (MODIFY — `delivery_driver`
  Data → Link(Driver))
- `klik_pos/klik_pos/custom/sales_invoice.json` (MODIFY — `custom_delivery_driver` Data →
  Link(Driver))
- `klik_pos/klik_pos/patches/` (New patch to backfill + a `patches.txt` entry)
- Update auto-match (Todo 022) and reconciliation write-back (Todo 023) to resolve/assign the
  driver Link instead of a raw string.

## Migration Strategy
- Add the `Link` fields alongside the existing text (or convert in place) and run a data patch:
  for each existing `delivery_driver` string, find a `Driver` by `driver_name` (case-insensitive)
  or Telegram identity; link if found, else leave blank and log for manual review.
- Restrict the Link with a filter to `status = Active` so rejected/pending drivers aren't selectable.

## Acceptance Criteria
- New Delivery Reports and Sales Invoices reference a `Driver` record, not free text.
- The backfill patch runs idempotently and reports how many rows linked vs. left unmatched
  (no silent drops — log the unmatched, per project convention).
- Auto-match and reconciliation set the driver Link correctly end-to-end.
- Existing data is preserved; unmatched free-text values remain visible for manual fixing.

## Dependencies
- Todo 025 (Driver DocType), and Phase 9 Todos 019/020/022/023 must exist first.

## Risks
- Changing a field's type from Data to Link in Frappe can require the stored value to be a valid
  Driver `name`; do the backfill in the same patch that changes the type, or stage via a new field
  then drop the old one.
- Free-text typos won't all match — accept a manual-review remainder rather than forcing bad links.
