# Todo 014: Backend Batch Pricing API for Customer-Specific Price Lists

## Description
Create an API endpoint that fetches item prices for multiple item codes based on the selected customer's price list priority hierarchy.

## Estimated Time
60-90 minutes

## Files to Change
- `klik_pos/api/item/item_price.py`

## Dependencies
- None

## Acceptance Criteria
- Endpoint batch fetches prices efficiently for a list of item codes.
- Price list priority is respected: Customer -> Customer Group -> POS Profile.

## Risks
- Performance bottlenecks if the number of item codes is very large and the query is not optimized.
