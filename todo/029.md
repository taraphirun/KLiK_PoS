**Status:** ❌ Dropped (2026-07-31) — Module 12 dropped, see phases/phase-11.md

## Description
List/browse Delivery Reports in KlikPOS with search and filters, replacing the bot frontend's
deliveries screen. Reads the Frappe `Delivery Report` doctype.

## Estimated Time
2-3 hours

## Files to Change
- `klik_pos/api/delivery.py` (MODIFY — add `list_delivery_reports(filters, start, limit)`)
- `klik_spa/src/pages/DeliveriesPage.tsx` (New)

## Requirements
- Filter by driver, `completion_status`, `payment_status`, `reconciliation_status`, and date range.
- Search by `reported_invoice_no` / `matched_invoice` / driver.
- Row shows: invoice no, driver, completion + payment status, recon status, timestamp, a GPS/map
  link, and photo/voice indicators.
- Paginated (mirror `useSalesInvoices` load-more pattern).
- Drill-in opens the report detail (photos, voice, GPS, matched invoice) with reconciliation
  actions (reuse Phase 9 Todo 023 endpoints).

## Acceptance Criteria
- List reflects Frappe data and filters correctly server-side.
- Opening a report shows all captured media and the current match state.
- `npm run build` passes.

## Dependencies

## Risks
- Large photo payloads — lazy-load media, don't inline base64.
- Keep list queries indexed on the common filter fields to avoid slow scans as volume grows.
