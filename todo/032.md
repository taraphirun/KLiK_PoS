# Todo 032: Live Map Page

**Status:** ⬜ Not started

## Description
A KlikPOS SPA page showing deliveries on a live Google Map, updating in real time from the Todo
031 events — the native port of the bot's `/live` screen.

## Estimated Time
3-4 hours

## Files to Change

## Requirements
- Initial load fetches recent/active deliveries (reuse Todo 029 list API), then subscribes to
  `delivery_report_update` for live changes.
- Pins colored by status; clustering when dense.
- Click a pin → detail popover with reconciliation actions (reuse Phase 9/11 components).
- Filter by driver / date / status, consistent with the deliveries list.

## Acceptance Criteria
- Map renders deliveries and updates live when a new report arrives or one is reconciled.
- Google Maps API key sourced from config, not hard-coded.
- `npm run build` passes (new map dependency compiles under Vite/React).

## Dependencies
- Todo 031 (realtime events), Todo 029 (list API)

## Risks
- Bundle size / map SDK — lazy-load the map route so it doesn't bloat the main POS bundle.
- Google Maps billing — ensure key restrictions and avoid unnecessary re-renders/tile reloads.
